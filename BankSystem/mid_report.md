## 二、系统总体设计

### 2.1 系统架构

本系统采用分层架构，共分为四层：

```
表现层：main.cpp（主界面 & 登录路由）+ ui.h/ui.cpp（控制台UI工具）
   ↓
业务层：EmployeeManager / CustomerManager / BankCardManager /
        TransactionManager / BankQueueManager /
        BranchGraphManager / SmartManager
   ↓
数据层：datastructs.h（LinkedList / Stack / Queue / PriorityQueue / Graph / GList）
   ↓
持久层：fileio.h/fileio.cpp（二进制文件序列化）→ data\ 目录
```

### 2.2 模块划分

系统共 10 个功能模块，对应源文件如下：

| 模块编号 | 模块名称 | 对应源文件 |
|:-------:|---------|-----------|
| 1 | 职员管理 | employee.h / employee.cpp |
| 2 | 客户账户管理 | customer.h / customer.cpp |
| 3 | 银行卡管理 | bankcard.h / bankcard.cpp |
| 4 | 存贷款业务 | transaction.h / transaction.cpp |
| 5 | 业务查询 | transaction.h / transaction.cpp（集成）|
| 6 | 排队管理 | bankqueue.h / bankqueue.cpp |
| 7 | 网点查询导航 | branchgraph.h / branchgraph.cpp |
| 8 | 智能管理 | smartmgr.h / smartmgr.cpp |
| 9 | 系统主界面 | main.cpp |
| 10 | 数据持久化 | fileio.h / fileio.cpp + types.h |

### 2.3 数据结构选型

| 数据结构 | 实现方式 | 使用场景 |
|---------|---------|---------|
| `LinkedList<T>` | 手写双向链表（模板类）| 所有主数据（职员/客户/银行卡/交易记录/网点）的存储与检索 |
| `Stack<T>` | 手写链式栈（模板类）| 操作历史（预留扩展接口）|
| `Queue<T>` | 手写链式队列（模板类）| 普通客户 FIFO 排队 |
| `PriorityQueue<T>` | 手写最大二叉堆（模板类）| VIP 客户优先排队（高优先级先出队）|
| `Graph` | 邻接矩阵（50×50 double）| 银行网点路网建模，支持 Dijkstra / BFS |
| `GList` | 广义表（递归嵌套节点）| 可视化展示客户-银行卡层级结构 |

### 2.4 角色权限设计

系统设三类用户角色，通过全局 `Session g_session` 管理会话状态：

- **管理员**：拥有全部权限，可管理职员账号
- **职员**：可操作客户、银行卡、业务、排队、导航、智能分析
- **客户**：只能操作自身数据（存取款、查询本人交易、取号、网点导航）

## 三、界面类型与技术

### 3.1 界面类型

本系统采用 **Windows 控制台字符界面（TUI）**，无需外部 GUI 库，直接在命令行终端运行。

### 3.2 技术实现

| 技术点 | 实现方式 |
|-------|---------|
| 彩色文字输出 | Windows Console API `SetConsoleTextAttribute`，定义 `Color::LCYAN`/`LGREEN`/`LRED`/`LYELLOW` 等颜色常量 |
| 密码屏蔽输入 | `_getch()` 逐字符读取，输入时显示 `*` 占位 |
| 控制台编码 | 启动时执行 `system("chcp 65001>nul")` 切换为 UTF-8，正确显示中文 |
| 菜单交互 | 自定义 `showMenu()` 函数，带编号列表，返回用户选择的序号（0 为返回/退出）|
| 表格展示 | `printTableHeader` / `printTableRow` / `printTableSep` 三函数组合绘制等宽对齐表格 |
| 横幅标题 | `showBanner()` 绘制 ASCII 方框横幅，`printHeader` / `printSubHeader` 绘制分割线标题 |

### 3.3 UI 颜色规范

| 颜色 | 用途 |
|------|------|
| 亮青色 | 一级标题、表格表头 |
| 亮绿色 | 操作成功提示 |
| 亮红色 | 错误提示、警告信息 |
| 亮黄色 | 警告、重要提示 |
| 亮白色 | 信息提示、普通内容 |
